### Hi, I'm Azizbek

I'm in grade 12 in Tashkent and I mostly make circuit boards: flight controllers, CanSat electronics, and boards that teach other kids to make circuit boards. The longer version, laid out like a component datasheet, is at **[notazizelse.xyz](https://notazizelse.xyz)**.

Right now I'm the lead electronics engineer for Uzbekistan's Orbita CanSat and IREC rocketry teams, organising [Haven Tashkent](https://haventash.xyz) (a free game jam for teenagers, 14–15 Nov), and teaching a PCB design class at Turin Polytechnic.

#### Boards

- **[CAMP v2](https://github.com/notazizelse/camp)** — the board for my Technocamp 2026 circuitry class. An 80 × 80 mm, all-through-hole Arduino Nano carrier that works like a CubeSat payload computer: temperature, humidity and CO on a screen and over USB. 200 students, ages 12–17.
- **[WiT](https://github.com/notazizelse/WiT)** — flight computer for a 3U stratospheric balloon payload: 4-layer STM32F407 board, two radios, seven science missions. Architecture and docs done; schematic in progress.
- **[Haven PCB badges](https://github.com/notazizelse/haven-pcb-badges)** — die-cut PCB name badges for Haven Tashkent. KiCad 10 project plus a Python script that generates the board art.
- **[Macropad](https://github.com/notazizelse/macropad)** — a 16-key Hack Club macropad: XIAO RP2040, OLED and per-key RGB on a 2-layer board.
- **[STM32 template](https://github.com/notazizelse/stm32_template)** — a Blue Pill (STM32F103C8T6) reference schematic in KiCad.

#### Software

- **[Haven Hub](https://github.com/notazizelse/haven-hub)** — a free team hub for Hack Club Haven organizers: tasks with proof, an admin dashboard, reminders and a public event page, all running on a Google Sheet the team owns. We run Haven Tashkent on it. [Try the demo](https://notazizelse.github.io/haven-hub/?demo=1&tour=1).
- **[Vocabio](https://github.com/notazizelse/vocabio)** — the SAT vocabulary trainer I built for myself: reads words aloud and picks up scheduling where Anki left off. Web, iPhone and Windows from one codebase, synced. Its listen mode became a standalone Anki add-on, **[anki-listen-mode](https://github.com/notazizelse/anki-listen-mode)**.
- **[LimitIO](https://github.com/notazizelse/limitio)** — daily time limits for specific websites and apps on Windows, enforced by a background service. The README says plainly what it can't stop.
- **[Haven Tashkent bot](https://github.com/notazizelse/haven-tashkent_bot)** — the Telegram registration bot for the jam: uz/ru/en, referrals, check-in tools.
- **[Jumpio](https://github.com/notazizelse/jumpio)** — my first game, a frog that jumps between islands. [Play it on itch.io](https://notazizelse.itch.io/jumpio).

#### Small tools

- [STM32 Homebrew fix for Mac](https://github.com/notazizelse/STM32_homebrew_fix_script_for_mac) — fixes the two build errors you get using Homebrew's `arm-none-eabi-gcc` with CubeMX projects.
- [GPS-Tracker](https://github.com/notazizelse/GPS-Tracker) — reads NMEA from a GPS module and draws the path on a live map.
- [lesson_descriptor](https://github.com/notazizelse/lesson_descriptor) — generates a PDF lesson description.

I work in KiCad, STM32CubeIDE, SolidWorks and Fusion 360, and write C, C++, Python and JavaScript. Best way to reach me: **notazizelse@gmail.com**.
